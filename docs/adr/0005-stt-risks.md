# ADR-0005: ریسک Google Web Speech و سیاست fallback

**وضعیت:** پذیرفته‌شده (T-0.7). اعتبارسنجی کیفیت (T-0.6) با `spikes/stt_compare.py` روی ماشین هدف.

## ریسک‌ها
- endpoint غیررسمی (`www.google.com/speech-api/v2/recognize`) با کلید عمومی؛ ممکن است rate-limit یا تغییر کند.
- حدود ~۶۰ ثانیه صدا در هر درخواست.
- صدا به سرور Google می‌رود (حریم خصوصی).

## سیاست
- timeout ۶۰ث، تا ۲ بار retry فقط برای خطای شبکه/۵xx (backoff ۰٫۵، ۱٫۵ث).
- خطای «نامفهوم» retry نمی‌شود (متن خالی).
- صدای بلند به تکه‌های ≤ ۵۰ث شکسته می‌شود.
- ۳ خطای **متوالی** → fallback خودکار به Vosk (اگر نصب باشد) + هشدار در overlay.
- هشدار حریم خصوصی هنگام اولین اجرا با `google_free`.
